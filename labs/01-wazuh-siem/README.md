# Lab 01 — Wazuh SIEM Setup

## Goal

Install and configure a basic Wazuh SIEM lab with one Windows endpoint connected to one Ubuntu Wazuh server.

This lab shows the basic SOC data flow:

Windows Endpoint → Wazuh Agent → Wazuh Manager → Wazuh Dashboard

## Lab Architecture

| Component | Machine | Role |
|---|---|---|
| Wazuh Manager | Ubuntu-SOC-Server | Receives and analyzes security data |
| Wazuh Dashboard | Ubuntu-SOC-Server | Web interface for viewing alerts and agents |
| Wazuh Indexer | Ubuntu-SOC-Server | Stores and searches security data |
| Wazuh Agent | WIN-ENDPOINT | Collects Windows logs and sends them to Wazuh |

## Machines Used

### Ubuntu SOC Server

- VM name: Ubuntu-SOC-Server
- Hostname: ubuntu-soc-server
- OS: Ubuntu Server 24.04.4 LTS
- IP address: 192.168.164.131
- Network mode: NAT
- SSH enabled: Yes
- Wazuh role: Manager, Dashboard, Indexer

### Windows Endpoint

- VM name: Windows-Endpoint
- Hostname: WIN-ENDPOINT
- OS: Windows 11 Pro
- IP address: 192.168.164.132
- Network mode: NAT
- Wazuh role: Agent / log source

## What Was Installed

### On Ubuntu-SOC-Server

Installed Wazuh all-in-one using the Wazuh installation script.

This installed:

- Wazuh Manager
- Wazuh Dashboard
- Wazuh Indexer
- Filebeat

The Wazuh dashboard was accessible from the host browser at:

https://192.168.164.131

The admin password is stored privately and is not included in this repository.

### On WIN-ENDPOINT

Installed the Wazuh Agent using the deployment command generated by the Wazuh dashboard.

The agent was configured with:

- Wazuh Manager IP: 192.168.164.131
- Agent name: WIN-ENDPOINT

The agent service was started using:

NET START Wazuh

## What I Learned

- Wazuh Manager is the central server that receives security data.
- Wazuh Agent runs on endpoints and sends logs to the manager.
- Wazuh Dashboard is used by the analyst to view agents, alerts, and security events.
- The Windows endpoint and Ubuntu server are connected through VMware NAT networking.
- Private lab IP addresses such as 192.168.x.x are safe to document, but passwords and keys should never be uploaded.
